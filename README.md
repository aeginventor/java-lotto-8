# 3주차 로또 미션 기능 목록

- [ ] `Lotto` 클래스 유효성 검사
    - [ ] 로또 번호 개수가 6개가 아닐 경우 예외 발생
    - [ ] 로또 번호에 중복된 숫자가 있을 경우 예외 발생
    - [ ] 로또 번호가 1~45 범위를 벗어날 경우 예외 발생
- [ ] 구입 금액 입력
    - [ ] 구입 금액이 숫자가 아닐 경우 예외 발생
    - [ ] 구입 금액이 1,000원 단위가 아닐 경우 예외 발생
    - [ ] 구입 금액이 1,000원 미만일 경우 예외 발생
- [ ] 구입 금액만큼 로또 발행 기능
- [ ] 발행된 로또 개수 및 번호(오름차순) 출력
- [ ] 당첨 번호 입력
    - [ ] 당첨 번호가 쉼표(,)로 구분되지 않거나, 숫자가 아닌 값을 포함할 경우 예외 발생
    - [ ] 당첨 번호 개수가 6개가 아닐 경우 예외 발생
    - [ ] 당첨 번호에 중복된 숫자가 있을 경우 예외 발생
    - [ ] 당첨 번호가 1~45 범위를 벗어날 경우 예외 발생
- [ ] 보너스 번호 입력
    - [ ] 보너스 번호가 숫자가 아닐 경우 예외 발생
    - [ ] 보너스 번호가 1~45 범위를 벗어날 경우 예외 발생
    - [ ] 보너스 번호가 당첨 번호와 중복될 경우 예외 발생
- [ ] 당첨 내역 계산 (등수별 몇 개인지)
- [ ] 당첨 통계 출력 (수익률 포함)
- [ ] 예외 발생 시 `[ERROR]` 메시지 출력 후, 해당 입력부터 다시 받기
